# Bar Model Equation Lab · Chun Academy

**Open it here:** https://chun1333.github.io/bar-model-lab/

Band 3 students make their own linear equation and then solve it step by step with animated bar models.

Type any linear equation in x (there is a keypad), or tap one of the examples.

Each step shows the bars, asks one question, and explains common mistakes. "I'm stuck" gives a hint, and "Show me" gives the answer. The working builds up beside the bars, and the last step checks the answer by putting it back into the equation.

How to read the bars (same as the printed Week 41 booklet): boxes are drawn to scale, a curly bracket shows what the boxes under it add up to, a striped part is taken away, and a grey bar is a negative amount.

It is a single self-contained file (`index.html`) and works offline. Maths is set with [KaTeX](https://katex.org) (MIT License), inlined with its fonts.
